## What this session settled

- Fiducial is a bundle compiler. Files are sources; agents receive `bin/bundle <audience>` output, never the repo. Harnesses are adapters downstream of bundles. Python 3, stdlib only, version pinned and checked.
- Bundles select by `audience:` frontmatter plus `order:`. `bin/bundle --list` emits every audience value in use. `all-decision-roles` is a new reserved value, defined in Pass 2.
- Two passes: Pass 1 reviews every non-code file against `docs/global-context/review-rubric.md`; Pass 2 reviews every `bin/` change with its own spec and tests.
- A directive is one line naming session (fresh or existing) and model tier, then one execution block as a paste block whose first instruction is to write the directive to a file, commit, push, and report the SHA. Nothing precedes it. Retired terms: dispatch, sync block, track. LEXICON records the retirements.
