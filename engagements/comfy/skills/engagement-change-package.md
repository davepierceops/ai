# Skill: Engagement Change Package

The lean change package for engagement work. One screen. The parent's
twelve-item package collapses to seven; nothing about the evidence chain is
lost, only the ceremony around it.

## Contents

1. **Intent** — what this change accomplishes, one paragraph, citing the
   Improvement Proposal (with its agreed acceptance criteria) or directive it
   derives from
2. **Blast radius** — what it touches; worst plausible outcome; rollback path
3. **Expected delta** — the pre-stated measurement claim, citing the baseline
   (or the logged override that waived it)
4. **The diff** — PR link
5. **Evidence** — what was verified, using the evidence classes precisely
   (plan-verified / apply-verified / serving-verified / delta-verified);
   what remains unverified
6. **Skeptic verdict** — attached verbatim, or the logged override
7. **Recommendation** — what should happen next, and any Dave decision points

## Rules

- a claim without a stated evidence class is not a claim, it is a mood
- overrides appear in the package itself, not only in the log
- if the change contradicts the System Map, the package includes the map
  correction
